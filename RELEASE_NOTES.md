## v0.1.0

First release for World of Warcraft Forever 1.60.1 and Zygor Guide Viewer Forever 1.6.

- Added a dark bronze theme for the quest viewer, guide selector, tabs, menus, and supported settings panels.
- Restyled quest progress bars and tinted the standard waypoint marker gold while keeping the arrow's direction colors.
- Added support for an existing local Expressway installation, with a WoW font fallback.

Requires `ZygorGuidesViewerForever` to be installed and enabled separately. The ZIP contains the skin only.
